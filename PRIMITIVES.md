# Primitives

> Atomic pieces of this Godot 4.7 project, grouped by domain; the file lives at the project root.

Status is `confirmed` (implementation read) or `inferred` (only seen referenced); `pending` marks code not yet committed to any branch. Scripts have no `class_name`: every piece is reached by `preload()`/`load()` path, group, method name, node name or metadata, so a rename breaks callers with no error. `dev/` folders hold sandboxes and probes, never primitives.

## cross-cutting contracts

- Physics layers (bit values) have no shared constant and no `layer_names` in `project.godot`; each module redeclares the values it uses, so renumbering one means editing every declaration: `1` ground and bridge (`world_collision.gd`, `catapult_tuning.gd`, `character_tuning.gd`, `player_controller.gd`, `pond_body.gd`, `liquid_curtain.gd`); `2` obstacles: trees, big bushes and rocks, buildings, walls, village props (`world_collision.gd`, `building_spawner.gd`, `village_props.gd`, `pond_body.gd`, `main.gd`, `catapult_tuning.gd`, `character_tuning.gd`, `camera_rig.gd`); `4` player (`character_tuning.gd`, `liquid_tower.gd`); `8` pick-only building bodies, clickable but walkable (`building_spawner.gd`); `16` invisible walk barriers at the island and pond rims (`world_collision.gd`, `character_tuning.gd`); `1 << 19` waterfall-curtain colliders, see [[PRIMITIVES#LiquidCurtain]]. `tuning.gd` `SHOULDER_COLLISION_MASK` is `1 | 2`.
- Global shader params are declared in `project.godot` `[shader_globals]`; each writer's entry names its readers, and a shader declaring a `global uniform` missing from that list fails to compile.
- Group names (`player`, `camera_rig`, `world_fx`, `fog_field`, `cloud_field`, `liquid_field`, `water_body`, `catapult_target`) are repeated as string literals in each module's code or `*_tuning.gd`, with no shared constant.
- Factories and `scripts/audio/sfx.gd` are loaded by string path behind `ResourceLoader.exists` (`main.gd`, `sfx_bridge.gd`, `liquid_feedback.gd`, `catapult_tuning.gd`), so moving or renaming one of those files disables that system silently.
- `world_collision.gd` copies the bridge arch formula of `bridge_builder.gd` and shares only its constants, so changing the arc in one file desyncs the deck collider from the mesh.

## buildings

Constants live in `scripts/buildings/building_tuning.gd`.

- **`BuildingFactory`**, `scripts/buildings/building_factory.gd`, confirmed, pending
  Single entry point that turns a building kind into a ready model and drives the building night state. Contract: static `kinds() -> Array[StringName]` (canonical spawnable list, excludes `wall`), `footprint(kind) -> Vector2i`, `display_name(kind) -> String` (pt-BR), `create(kind) -> Node3D` (independent tree, origin at the footprint center on y = 0, front +Z, idle animation included), `create_wall(neighbors)` (bitmask bit0 +X, bit1 -X, bit2 +Z, bit3 -Z), `set_night(tree, amount)` (forwards to [[PRIMITIVES#BuildingMaterials]] and calls `apply_night` on group `building_night_lights`); a new kind goes into `kinds()`, `_FOOTPRINTS`, `_NAMES` and the `create()` match, and one missing from `kinds()` spawns as a placeholder with no error; `_FOOTPRINTS` is read by reflection in `catapult_controller.gd` and mirrored by `BaseLayout.FALLBACK_FOOTPRINTS`, so renaming or changing it silently desyncs both; model node contract: `water_tower` exposes `TankPivot`, `TankPivot/PourPoint`, `TankPivot/FillSurface` and `water_button` exposes `ButtonCap` (found by name anywhere, [[PRIMITIVES#LiquidTower]]), `catapult` exposes `ArmPivot`, `ArmPivot/Seat`, `ArmPivot/Bucket`, `Winch`, `CountdownAnchor` and root meta `fire_angle_deg` (read by exact path, [[PRIMITIVES#CatapultController]], so they must stay at those paths); kinds are compositions in `scripts/buildings/kinds/`.
  Consumers: 3 (building_spawner, day_night, catapult_controller via `_FOOTPRINTS`), plus 3 dev (building_gallery, catapult_sandbox, liquid_sandbox).
- **`BuildingMeshKit`**, `scripts/buildings/mesh_kit.gd`, confirmed, pending
  Static generator of the building shape vocabulary (beveled, UV-mapped, normal-correct solids and roofs) that Godot primitive meshes lack. Contract: static generators such as `rounded_box`, `lathe`, `cylinder`, `cone`, `dome`, `hip_roof`, `gable_roof`, `prism`, `extrude`, `arch`, `rock` (full list in the file); boxes, cylinders and spheres are centered, cones, domes and roofs sit on y = 0; roofs return surface 0 = tiles and surface 1 = fascia and underside; every generator caches by its parameters and returns the shared mesh, so callers set materials per instance and never mutate it; `extrude` with a `key_hint` caches by the hint alone, so two outlines under one hint get the first mesh; not interchangeable with [[PRIMITIVES#WorldMeshKit]]: this one outputs cached UV meshes for the textured building shaders, the other batches vertex-colored meshes, and they share only the low-level triangle accumulator idea.
  Consumers: 14 (13 kinds plus BuildingParts), plus 1 dev (building_gallery).
- **`BuildingMaterials`**, `scripts/buildings/materials.gd`, confirmed, pending
  Building palette and cache of shared materials, the only loader of `shaders/buildings/*.gdshader` and the owner of the building night state. Contract: palette color constants; cached factories per look (`stone`, `planks` with `local_uv` for tilted or animated parts, `roof`, `wood`, `metal`, `window_glow`, `lantern`, `water`, `mana_liquid`, `glass`, `flag` and others in the file); `set_night(amount)` mutates the cached night-aware materials in place; static `night_amount` read by lights created mid-transition; materials are shared per key, so changing a returned one changes every building, and `lantern()` rewrites its cached emissive, which an `emissive()` call with the same arguments also receives; building shaders read no shader globals, so building night follows `BuildingFactory.set_night`, not the global `night_amount` of [[PRIMITIVES#DayNight]].
  Consumers: 17 (13 kinds, BuildingParts, BuildingFactory, anim/light_pulse, NightLight), plus 1 dev (building_gallery).
- **`BuildingParts`**, `scripts/buildings/parts.gd`, confirmed, pending
  Assembly vocabulary every building kind is written in: placement conventions plus the recurring details and idle animators. Contract: static `mesh`, `box` (centered), `block` and `cyl` (bottom at `pos.y`), `rod(from, to)`, `roof`, `cone_roof`, `pivot`, `animated(script, props, ...)` with `spinner`/`bobber`/`swayer` over `anim/spin.gd`, `anim/bob.gd`, `anim/sway.gd` (`anim/scan.gd` is attached directly by the cannon), `footing`, `window`, `door`, `flag`, `lantern` (yaw 0 = +Z), `smoke`, `bubbles`, `night_light`, `mana_light` (`anim/light_pulse.gd`), `local_aabb(root)` (works before entering the tree), `coin`, `gold_heap`; materials are set per instance, never on the cached mesh; `building_spawner.gd` keeps its own `_local_aabb` that skips Label3D and particles, so the two return different bounds.
  Consumers: 13 (every kind in `scripts/buildings/kinds/`).
- **`NightLight`**, `scripts/buildings/anim/night_light.gd`, confirmed, pending
  Warm OmniLight3D script that switches on past its own random night threshold with a pop and flicker. Contract: attached with `set_script` on an `OmniLight3D` (through `BuildingParts.night_light` and `lantern`); joins group `building_night_lights` in `_ready`; `apply_night(amount, instant = false)` called by `BuildingFactory.set_night`; reads `BuildingMaterials.night_amount` on `_ready`, so lamps spawned at night start lit; separate from the world group `night_lights` that [[PRIMITIVES#DayNight]] scales.
  Consumers: 2 (BuildingParts, BuildingFactory).
